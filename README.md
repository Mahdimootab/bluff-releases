# بلوف — دریافت نسخهٔ اندروید

بلوف یک بازی کارتی فارسی با میز زمردی و طلایی است؛ می‌توانید با دوستانتان در اتاق خصوصی آنلاین بازی کنید یا بازی محلی با بات‌ها را انتخاب کنید.

این مخزن فقط برای انتشار فایل نصب و اطلاعات نسخه‌هاست. سورس بازی، اطلاعات بازیکنان و کلید امضای برنامه در آن منتشر نمی‌شوند.

## نسخهٔ آزمایشی اندروید

| مشخصه | مقدار |
| --- | --- |
| نسخه | `0.2.0-beta.1` — کد `3` |
| نام برنامه | بلوف بتا |
| شناسهٔ اندروید | `app.bluffgame.beta` |
| حداقل اندروید | اندروید ۷، API 24 |
| حجم فایل | ۳٬۸۹۶٬۰۱۵ بایت، حدود ۳٫۹ مگابایت |
| اجرا | رابط و تصاویر داخل APK، با Android System WebView |

این APK برای اجرای بازی Chrome یا نصب PWA را باز نمی‌کند. Android System WebView باید روی دستگاه موجود و به‌روز باشد. بازی آنلاین به اینترنت نیاز دارد.

**انتشار بتا فعال است:** فایل نصب امضاشده در GitHub منتشر شده و سایت معرفی، آموزش و دریافت نیز در دسترس است.

- [صفحهٔ نسخه و توضیح تغییرات](https://github.com/Mahdimootab/bluff-releases/releases/tag/v0.2.0-beta.1)
- [سایت معرفی و آموزش](https://bluff-game-site.silkroad-games-beta.workers.dev/)

آیفون و آیپد از نسخهٔ وب استفاده می‌کنند؛ برای نصب PWA، صفحهٔ خود بازی را در Safari باز کنید و از Share، گزینهٔ Add to Home Screen را بزنید. نصب و اجرای iOS در این تحویل روی دستگاه واقعی بررسی نشده است.

## نصب و به‌روزرسانی

APK را در گوشی اندرویدی دریافت و باز کنید. اگر اندروید اجازهٔ نصب خواست، اجازه را فقط برای همان مرورگر یا برنامهٔ دریافت‌کننده فعال کنید. برای نسخه‌های بعد، برنامهٔ بلوف بتا را حذف نکنید؛ فایل امضاشدهٔ جدید با همین شناسه و امضا روی نسخهٔ قبلی نصب می‌شود.

نسخهٔ اندروید فضای ذخیرهٔ جدا از Chrome و PWA دارد؛ انتقال خودکار بازی ذخیره‌شده یا هویت اتاق از مرورگر به APK ارائه نشده است.

## بررسی فایل

SHA-256 فایل نصب:

```text
1df4ccf6571de3fa173ea73d528dd7dc6f5b17c9f00156ffa6bb062f9f6c91e0
```

برای مقایسه در PowerShell:

```powershell
Get-FileHash -Algorithm SHA256 .\bluff-beta-0.2.0-beta.1.apk
```

هش به تشخیص نقص یا تغییر فایل کمک می‌کند و جایگزین اعتبار ناشر نیست. اثرانگشت عمومی گواهی امضای بتا در `release-manifest.json` آمده است.

## وضعیت بررسی

ساخت، امضا، بسته‌بندی و ۶ آزمون اندروید موفق‌اند. کاربر بازشدن همین APK بدون Chrome، انجام حرکت و اجرای نوبت بات‌ها را روی گوشی تأیید کرده است. اجرای آفلاین، بازی آنلاین، reconnect، بازگشت و چرخش صفحه در همین APK هنوز تأیید دستگاهی ندارند؛ نتایج وب و PWA به APK تعمیم داده نمی‌شوند.

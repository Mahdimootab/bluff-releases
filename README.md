# بلوف — دریافت نسخهٔ اندروید

بلوف یک بازی کارتی فارسی با میز زمردی و طلایی است؛ با دوستانتان در اتاق خصوصی آنلاین بازی کنید یا بازی محلی با بات‌ها را انتخاب کنید.

این مخزن فقط برای انتشار فایل نصب و اطلاعات نسخه‌هاست. سورس بازی، اطلاعات بازیکنان و کلید امضای برنامه در آن منتشر نمی‌شوند.

نسخهٔ `0.3.0-beta.1` منتشر شده است؛ لینک‌های زیر فایل نصب جدید و اطلاعات همین انتشار را باز می‌کنند.

| مشخصه | مقدار |

| نام برنامه | بلوف بتا |
| شناسهٔ اندروید | `app.bluffgame.beta` |
| حداقل اندروید | اندروید ۷، API 24 |

نوبت بازیکن در این نسخه محدودیت زمانی ندارد؛ پاس، ردشدن نوبت یا قبول خودکار به‌علت گذشت زمان انجام نمی‌شود. بات‌ها همچنان با مکث ۱۰ تا ۱۵ ثانیه‌ای حرکت می‌کنند. حالت تمام‌صفحه و سربرگ فشرده با «رویدادها» کنار تنظیمات نیز در این نسخه قرار دارند.

این APK برای اجرای بازی Chrome یا نصب PWA را باز نمی‌کند. Android System WebView باید روی دستگاه موجود و به‌روز باشد. بازی آنلاین به اینترنت نیاز دارد.

## نصب و به‌روزرسانی

APK را در گوشی اندرویدی دریافت و باز کنید. اگر اندروید اجازهٔ نصب خواست، اجازه را فقط برای همان مرورگر یا برنامهٔ دریافت‌کننده فعال کنید. برنامهٔ بلوف بتا را حذف نکنید؛ فایل امضاشدهٔ جدید با همین شناسه و امضا روی نسخهٔ قبلی نصب می‌شود.

ذخیرهٔ APK از Chrome و PWA جداست؛ انتقال خودکار بازی ذخیره‌شده یا هویت اتاق از مرورگر به APK ارائه نشده است. مهلت بازگشت پس از قطع اتصال آنلاین جدا از زمان نوبت است: قطع بیش از پنج دقیقه می‌تواند مسابقه را ناتمام کند.

## بررسی فایل

SHA-256 فایل نصب:

```text
523d0beb01656350ef375fb364d9b99ea3ad9f0d9f31448d136f8a19d242cb4c
```

برای مقایسه در PowerShell:

```powershell
Get-FileHash -Algorithm SHA256 .\bluff-beta-0.3.0-beta.1.apk
```

هش به تشخیص نقص یا تغییر فایل کمک می‌کند و جایگزین اعتبار ناشر نیست. اثرانگشت عمومی گواهی امضای بتا در `release-manifest.json` آمده است.

## وضعیت بررسی

ساخت، TypeScript، lint و امضای این نسخه موفق‌اند. شش آزمون Java موفق قبلی توسط Gradle به‌صورت UP-TO-DATE استفاده شدند؛ اجرای تازهٔ آن شش آزمون ادعا نمی‌شود. کاربر روی APK جدید حفظ ذخیره، نبود تایمر و انجام حرکت پس از بیش از ۴۵ ثانیه انتظار بدون پاس خودکار را تأیید کرد. یکپارچگی بسته و دانلود کامل ناشناس فایل عمومی نیز با اندازه و SHA صحیح بررسی شدند. آزمون آنلاین شش‌نفره با بازیکنان مصنوعی روی آدرس عمومی و آزمون به‌روزرسانی/آفلاین PWA در مرورگر دسکتاپ موفق بودند؛ این نتایج، آزمون آنلاین یا آفلاین خود APK روی گوشی محسوب نمی‌شوند. جزئیات در `release-manifest.json` و یادداشت انتشار آمده است.

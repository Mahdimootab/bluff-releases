کد اندروید `16` · بستهٔ ثابت `app.bluffgame.beta`

- ارتباط حساب فقط با نشانی امن HTTPS انجام می‌شود؛ ارسال اطلاعات روی HTTP عمومی پیش از درخواست مسدود است.
- حساب کاربری اختیاری با نام کاربری و رمز؛ بازی مهمان همچنان در دسترس است.
- نام، یکی از ۱۰ آواتار و خلاصهٔ کارنامه بین APK، وب و PWA همگام می‌شوند. افزودن پروفایل و سوابق مهمان انتخابی است و نسخهٔ مهمان حفظ می‌شود.
- نتایج تکراری دوباره شمرده نمی‌شوند؛ تغییر هم‌زمان پروفایل با انتخاب نسخهٔ دستگاه یا ابری حل می‌شود. دادهٔ هر حساب جدا از حساب دیگر است.
- کد خصوصی بازیابی فقط یک‌بار نمایش داده می‌شود. آن را جای امن نگه دارید و برای دیگران نفرستید. بازیابی رمز، نشست‌های قبلی و کد قبلی را لغو می‌کند؛ بازیابی با ایمیل یا تلفن فراهم نیست.
- بازی جاری، کارت‌ها، تنظیمات دستگاه، قواعد بدون تایمر، مکث قابل تنظیم بات‌ها و ظاهر زمردی و طلایی حفظ شده‌اند. کارنامهٔ شخصی، رتبه‌بندی رسمی نیست.

APK همان گواهی مستقل قبلی را دارد؛ آن را روی نسخهٔ قبلی نصب کنید و برنامه را حذف نکنید. بازی محلی داخل APK قرار دارد و Android System WebView لازم است. ورود حساب، همگام‌سازی و اتاق آنلاین اتصال می‌خواهند. اطلاعات حسابِ قبلاً دریافت‌شده و نتایج تازه به‌صورت محلی حفظ می‌شوند و با اتصال همگام می‌شوند.

ساخت، lint و امضا موفق‌اند؛ تمام۶۰فایل اجرایی و manifest تطبیق داده شدند و۵۵دارایی هنر/فونت/صدا بدون تغییرند.۱۵۰آزمون وب و۶۶آزمون سرور موفق‌اند؛۹آزمون Native نتیجهٔ کش‌شده دارند. نتیجهٔ بررسی دستگاه و سرور عمومی در گزارش انتشار جدا ثبت می‌شود.

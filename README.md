## بررسی همین نسخه

ساخت نهایی Android، lint و بررسی امضا با خروجی صفر موفق‌اند؛ فهرست دقیق۶۰ فایل بسته و هش‌ها تطبیق یافتند. هر۵۱ تصویر، فونت و آیکن نسخهٔ۰٫۶ یکسان است. چهار WAV با مجموع۲۴۵۲۰۶بایت، MIME درست و SHA مطابق منبع بسته‌اند؛ chunk نمایشی JS و CSS نیز داخل APK هستند. متن مجوزهای Motion و بستهٔ صوتی در تنظیمات آفلاین در دسترس است.

۱۰۴ آزمون وب/کنترلر موفق‌اند، شامل۱۲ آزمون صدای فایل‌محور و۶ آزمون planner. ۹ آزمون Java با منطق بومی تغییرنکرده `UP-TO-DATE` بودند؛ اجرای تازهٔ کد۱۱ محسوب نمی‌شوند. اجرای تازهٔ آزمون‌های آنلاین در این مرحلهٔ رابط ادعا نمی‌شود؛ پروتکل سرور تغییر نکرده است.

در مرورگر محلی، fixture توسعه در۳۹۰×۸۴۴،۳۹۰×۶۸۰ و۱۳۶۵×۷۶۸ حرکت پخش، flip مجاز، جمع‌شدن، برنده، کاهش حرکت و حفظ انتخاب هنگام resize را نشان داد. این شاهد بازی طبیعی کامل یا اجرای گوشی نیست. کاربر صدای واقعی نسخهٔ کاندید کد۱۱ را روی گوشی مناسب تأیید کرد؛ چهار فایل صوتی بستهٔ نهایی همان هش‌ها را دارند. دانلود عمومی همین فایل تأیید شد؛ نصب مجدد بستهٔ نهایی، لرزش، کارایی و اجرای نسخهٔ عمومی/PWA به شاهد مستقل نیاز دارند.

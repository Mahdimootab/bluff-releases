# بلوف — ۰٫۹٫۲-beta.1، کد۱۹

موسیقی پس‌زمینهٔ Covert Affair با کنترل مستقل روشن/خاموش و بلندی صدا اضافه شد. پیش‌فرض۲۰٪ است؛ پس از نخستین لمس شروع می‌شود و در میز بازی آرام‌تر پخش می‌شود. تنظیم موسیقی جدا از صدای کارت‌ها ذخیره می‌شود. با مخفی‌شدن صفحه یا توقف برنامه، پخش متوقف و پس از بازگشت ادامه داده می‌شود.

قطعهٔ کامل همراه APK و حافظهٔ آفلاین PWA است؛ پخش از سرویس موسیقی خارجی انجام نمی‌شود. فایل اصلی۷٬۷۶۹٬۸۹۶بایت و بدون بازفشرده‌سازی است. کارت‌ها و ظاهر منتخب، موتور و قواعد بدون تایمر، مکث بات‌ها، حساب و پروفایل، بازی مهمان و ذخیره‌های قبلی حفظ شدند.

APK جدید را روی برنامهٔ فعلی نصب کنید؛ آن را حذف نکنید. مسیر دریافت از داخل برنامه: تنظیمات ← «بررسی نسخهٔ تازه» ← «دریافت به‌روزرسانی». نام بسته و امضا همان قبلی است. APK از Android System WebView استفاده می‌کند و به اجرای Chrome وابسته نیست. در وب/PWA، از تنظیمات خانه «بررسی نسخهٔ تازه» و پس از آماده‌شدن «دریافت نسخهٔ تازه» را بزنید.

۱۶۴ آزمون وب و۱۳ آزمون Java واقعاً اجرا و موفق شدند. ساخت، امضا و lint اندروید موفق‌اند؛ lint شش هشدار و صفر خطا دارد. هر۶۴فایل بسته با manifest بررسی و MP3 در وب، خروجی بومی و خود APK با فایل اصلی تطبیق داده شد. در مرورگر واقعی، پیش از لمس هیچ player ایجاد نشد؛ سپس پخش با موج صوتی غیرصفر، یک player، تغییر بلندی، کاهش صدا در میز، تکرار از انتهای قطعه، خاموش/روشن و حفظ تنظیمات بررسی شد. reload و پخش آفلاین PWA و پاسخ۲۰۶ برای بازهٔ MP3 هم موفق بود.

اجرای APK روی گوشی یا شبیه‌ساز تأیید نشده است: کاربر امکان اتصال گوشی ندارد و AVD آماده‌ای وجود ندارد. رویدادهای pause/resume در مرورگر شبیه‌سازی و آزمون شدند؛ تغییر واقعی visibility در محیط Chromium آزمون مشاهده نشد. آزمون تازهٔ iPhone، آفلاین گوشی و مسابقهٔ کامل آنلاین انجام نشدند. بررسی عمومی نیز موفق شد:۶۹فایل بازی و۱۹فایل سایت،۶۵ورودی آفلاین، API کد۱۹، لینک سایت و دانلود کامل APK با هش دقیق تأیید شدند. ایراد اولیهٔ Range سرور حفظ و اصلاح شد؛ پاسخ‌های۲۰۶و۴۱۶فایل صوتی دوباره بررسی شدند. ارتقای PWA عمومی، بدون پاک‌کردن داده، همان۱۳کارت را حفظ کرد؛ یک حرکت معتبر با موسیقی ثبت و پخش آفلاین روی آدرس اصلی هم تأیید شد.

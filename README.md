# بلوف — ۰٫۸٫۲-beta.1

کد اندروید `14` · شناسهٔ ثابت `app.bluffgame.beta`

- اصلاح نمایش قاب دکمه‌ها، پلاک نام و نشانگر تعداد کارت‌ها در صفحه‌های کوچک؛ همان تصاویر زمردی و طلایی با برش HTML و اندازهٔ پیکسلی حفظ شده‌اند.
- تنظیمات و پنجره‌های جزئیات فاصلهٔ امن بریدگی و لبهٔ پایین نمایشگر را رعایت می‌کنند؛ هم‌پوشانی نوشته‌ها در ارتفاع کم اصلاح شده است.
- وب، PWA و APK از یک رابط مشترک ساخته می‌شوند. کاربر رفع ایراد نمایش آیفون را تأیید کرده است؛ شمارهٔ build دیده‌شده روی دستگاه گزارش نشده است.
- قواعد بدون تایمر، مکث قابل تنظیم بات‌ها با پیش‌فرض ۵ ثانیه، اتاق‌های ترکیبی انسان و بات، پروفایل، کارنامه و ذخیره‌ها حفظ شده‌اند.

APK امضاشده با همان گواهی نسخهٔ قبلی ساخته شده؛ بسته، کد اندروید و امضا برای ارتقای مستقیم سازگارند. برنامه را حذف نکنید و APK را روی نسخهٔ قبلی نصب کنید. همهٔ رابط، تصاویر، صدا و بازی محلی در APK قرار دارند؛ Android System WebView لازم است. بازی آنلاین اینترنت می‌خواهد.

ساخت، typecheck، lint و کنترل امضا موفق‌اند. تمام ۶۰ فایل بسته تطبیق داده شدند؛ ۵۵ فایل هنر، فونت و صدا و کد DEX با نسخهٔ قبلی یکسان‌اند. ۹ آزمون Native نتیجهٔ موفق کش‌شده دارند و اجرای تازه محسوب نمی‌شوند. بررسی عملکرد دستگاه برای این کد، در گزارش انتشار جدا ثبت می‌شود.
